## Ask a question or report a bug

Search the [issue tracker](https://github.com/QuinntyneBrown/agent-toolkit/issues)
for an existing discussion. If none covers the problem,
[open an issue](https://github.com/QuinntyneBrown/agent-toolkit/issues/new) with
a descriptive title and enough context to reproduce or understand it.

For a bug report, include:

- The skill or script involved and the toolkit revision from `git rev-parse HEAD`.
- The operating system and agent version; include Python, Java, and PlantUML
  versions for rendering problems.
- Whether the skill is installed for one project or for the current user.
- The prompt or command used, minimal input, and steps to reproduce the problem.
- Expected and actual behavior, including relevant diagnostic output.

Use synthetic examples and remove credentials and private project data. Describe
any local skill modifications that could affect the result.

## Request a feature

Explain the workflow that needs improvement, the current limitation, and the
output that would be useful. Include a representative request the skill should
handle and explain how the capability would apply across projects.

Issue responses depend on maintainer availability. A response or delivery date
is not guaranteed. For problems with an agent host or external tool itself,
use that product's support channel.
